# 🛡️ Aman Bot AI (أمان بوت)
**AI-Powered Cyber Scam Detection Assistant**  
*Built for SCAMSHIELD AI Hackathon — Abu Dhabi Police x 42 Abu Dhabi*

## 📌 Overview
**Aman Bot** is a multimodal AI assistant designed to protect UAE residents and senior citizens from digital fraud, phishing links, and fake social media ads in real time—without requiring any app installation.

## ✨ Key Features
- **Multimodal Scam Analysis (Text & Images):** Analyzes suspicious SMS/WhatsApp messages, URLs, and screenshots of fake ads.
- **3-Tier Risk Classification:**
  - 🔴 **Confirmed Scam:** Detects urgency tactics, spoofed domains, and OTP/card theft attempts.
  - 🟡 **Suspicious:** Advises caution and verification.
  - 🟢 **Safe:** Confirms legitimate notifications (e.g., standard bank purchase alerts).
- **Direct Aman Service Guidance:** Connects users immediately with Abu Dhabi Police's **Aman Service** reporting channels.
- **Privacy by Design:** Zero personal data or chat logs are permanently stored.

## 🛠️ Tech Stack
- **AI & Conversation Engine:** Botpress Cloud AI Agent (LLM + Vision)
- **Presentation & UI Design:** Canva / PowerPoint
